# Zaevlad Solidity audit findings

The following folder includes a data dump of Solidity security vulnerabilities extracted from the [Zaevlad/audit-findings-dataset](https://huggingface.co/datasets/Zaevlad/audit-findings-dataset) dataset on Hugging Face. The scope of the dump is findings marked as **Critical**, **High** or **Medium**, split across one file per severity. Each entry holds a `title`, a `content` field with the full write-up and a `summary`. The following data is used to enrich the capabilities of the subagents spawned by the [smart-contract-analyzer](../../.claude/skills/smart-contract-analyzer/).

The date of the export snapshot is 22nd September 2026.
