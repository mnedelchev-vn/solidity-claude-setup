# Solodit Solidity vulnerabilities

The following folder includes a data dump of Solidity security vulnerabilities extracted by [https://solodit.cyfrin.io/](https://solodit.cyfrin.io/). The scope of the dump is vulnerabilities marked as **Medium** or **High** and the secondary filter was to query only Solidity related issues as the Solodit platform provides data for several programming languages. The following data is used to enrich the capabilities of the subagents spawn by the [smart-contract-analyzer](.claude/skills/smart-contract-analyzer/).

The date of the export is 1st June 2026.
